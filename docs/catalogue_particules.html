Intégration dans Godot

Chaque planche est une grille régulière : largeur de l'image du GIF = largeur d'une image. Dans Godot, un AnimatedSprite2D avec un SpriteFrames découpé en grille (colonnes = largeur de la planche / largeur d'une image) suffit ; jouer l'animation une fois puis libérer le nœud pour les effets ponctuels. Les cases vides de fin de grille sont à exclure. Les effets de 96 px couvrent 3 cases du jeu : prévoir un centrage sur la case et éventuellement une échelle de 0,5 à 1 selon l'effet.
